# Мини-приложение "Обменник" для Telegram

Простое мини-приложение для обмена валют с интерфейсом, аналогичным предоставленному дизайну.

## Функциональность
- Покупка и продажа валюты
- Выбор валюты: RUB, EUR, KZT, BYN
- Расчет суммы по текущему курсу
- Адаптивный дизайн для мобильных устройств

## Как запустить приложение

### Вариант 1: Локальный запуск для тестирования
1. Скачайте все файлы в одну папку
2. Откройте файл `index.html` в браузере
3. Приложение будет работать в режиме эмуляции Telegram Web App

### Вариант 2: Запуск в Telegram
1. Создайте бота через [BotFather](https://t.me/botfather) в Telegram
2. Настройте мини-приложение:
   - Отправьте команду `/newapp` BotFather
   - Следуйте инструкциям, укажите название и описание
   - В качестве URL укажите адрес, где размещено ваше приложение
3. Для тестирования разместите файлы на хостинге:
   - GitHub Pages (бесплатно)
   - Vercel, Netlify или подобные сервисы
   - Любой веб-хостинг с поддержкой статических файлов

### Вариант 3: Быстрое развертывание на GitHub Pages
1. Создайте репозиторий на GitHub
2. Загрузите все файлы в репозиторий
3. В настройках репозитория включите GitHub Pages
4. Используйте полученный URL для мини-приложения

## Структура проекта
- `index.html` - Основной HTML файл
- `style.css` - Стили приложения
- `app.js` - Логика приложения и интеграция с Telegram Web App
- `README.md` - Инструкция по запуску

## Интеграция с Telegram Web App
Приложение использует Telegram Web App SDK для:
- Определения размера окна
- Управления основной кнопкой
- Отправки данных обратно в бота
- Получения данных о пользователе (при необходимости)
